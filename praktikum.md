# Praktikum

Auf dieser Seite finden Sie alle Informationen und Materialien zum Praktikum des Moduls "Cyber-Physische Systeme".

## Kalman-Filter 2D Lokalisierung

Im Rahmen dieses Praktikums wird ein Kalman-Filter zur 2D-Lokalisierung eines Fahrzeugs in einer Simulationsumgebung implementiert und evaluiert.

### Download

Laden Sie das Quellcode-Paket für das Praktikum herunter:

- [📄 kalman_localization_2d.zip]({{ '/assets/praktikum/kalman_localization_2d.zip' | relative_url }})  

### Hinweise zur Durchführung

1. Entpacken Sie die Datei `kalman_localization_2d.zip` lokal auf Ihrem Rechner.  
2. Befolgen Sie die Installationsanweisungen in `docs/installation.md` bzw. `README.md`.  
3. Implementieren Sie die geforderten Methoden in `student_task.py`.  
4. Starten Sie das Praktikum und die Simulation über `manager.py`.
